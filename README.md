# Rhett Dawson: personal site

One-page personal site for Rhett Dawson, live at https://rhettd333.github.io/ (no custom domain yet, by owner direction).

Plain static HTML and CSS. Pushes to main deploy to GitHub Pages through the workflow in .github/workflows/deploy.yml, which publishes only the allowlisted site files. BRIEF.md, MISSION.md, and BACKLOG.md govern the build and are never published.

Managed by Muse as scrum master with Codex as the dev team, the same system as Boston Capital Strategy. The live work list is BACKLOG.md.
